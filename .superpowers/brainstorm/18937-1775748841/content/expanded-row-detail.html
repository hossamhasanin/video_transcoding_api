Key Design Details

  • Expand arrow (▶/▼) in first column — clickable entire row
  • Blue left border for completed/processing, red left border for failed
  • 2-column grid inside detail panel for scannable layout
  • Error field spans full width when present, highlighted in red
  • Only one row expanded at a time
